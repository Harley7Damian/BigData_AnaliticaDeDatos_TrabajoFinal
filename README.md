## Adquisición y preprocesamiento de datos

Esta rama contiene los notebooks de Databricks que documentan de manera estructurada cada etapa del flujo de datos desarrollado en el proyecto. Se incluye la adquisición de datos desde fuentes internas, exportadas a formato CSV para su procesamiento distribuido mediante PySpark DataFrames, asegurando trazabilidad y consistencia.

Asimismo, se detalla el análisis exploratorio de datos (EDA) orientado a la comprensión de las variables, detección de patrones y evaluación de calidad, complementado con procesos de limpieza, transformación y reducción de datos. Cada notebook describe el objetivo de la etapa, las decisiones técnicas adoptadas y los resultados obtenidos, dejando evidencia del razonamiento analítico aplicado antes de la construcción de modelos y reportes.
